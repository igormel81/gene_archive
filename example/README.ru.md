# Пример: семейный архив Харперов и Новаков

**[English version](README.md)**

Полный демонстрационный сайт движка. **Всё и все в нём вымышлены**: люди, события, записи,
ссылки на источники, корабли и газеты придуманы для примера, а «фотографии» и «сканы» в
`sources/` нарисованы программой. Настоящие места (Луисбург, Ков, остров Эллис, Питтсбург,
Капушаны, Гамбург, Чикаго, Уиндбер) — только фон; ссылки на `example.org` никуда не ведут.

Данные показывают все возможности: 46 человек в семи поколениях, развод, усыновление,
братья и сёстры с неизвестными родителями, вероятные дети и «возможная родня» без
установленной связи, разные версии дат рождения и смерти, скрытый документ (`S21`), живые
люди (семья главного человека), места с переездами на карте, журнал поиска и рассказ на
странице «История».

| Файл | Что |
|---|---|
| `site.json` | настройки сайта: название, главный и стартовый человек, ветви, вопросы, лента «Истории» |
| `family_tree.json` | люди, семьи, источники, места, журнал исследования |
| `sources/` | изображения документов и двухстраничный PDF |
| `content/story.html` | страница «История» |

Тексты примера — на английском; сайт собирается на английском, русском и румынском:
интерфейс переводится, а тексты остаются английскими (см. [переводы](../docs/translations.ru.md)).

Собрать и посмотреть:

```sh
gene build example
gene serve example
```
