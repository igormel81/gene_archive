# Языки и переводы

**[English version](translations.md)**

## Интерфейс

Интерфейс (кнопки, заголовки, справку) переводит движок. Языки выбираются в `site.json`:

```json
"languages": ["ru", "en", "ro"]
```

Первый язык публикуется в корне сайта, остальные — в `/en/`, `/ro/`. В шапке появляется
меню языков; при переключении остаётся открытым тот же человек, документ или место.

Доступны: **русский, английский, румынский**. Новый язык интерфейса — это pull request
с одним файлом, см. [CONTRIBUTING](../CONTRIBUTING.ru.md#новый-язык-интерфейса).

## Ваши тексты

Имена не переводятся никогда. Остальное — заметки, названия и расшифровки документов,
описания мест, рассказ — остаётся как вы написали, пока вы не добавите перевод. Переводы
лежат в папке сайта:

```
my-family/translations/en.json
```

```json
{
  "Родился в деревне Красное.": "Born in the village of Krasnoye.",
  "Метрическая книга церкви села Красное, 1895": "Birth register of Krasnoye church, 1895"
}
```

Ключ — точный исходный текст (абзац целиком), значение — перевод. Список текстов без перевода:

```sh
gene translations my-family en > todo-en.json
```

Команда выводит JSON с пустыми значениями: заполните их и перенесите в `translations/en.json`.
Абзац со ссылками или выделением переводится целиком, вместо тегов — метки:
`"Подробнее в <1>Истории</1>."` → `"More in the <1>Story</1>."` — метки должны остаться те же.

Непереведённые тексты показываются на языке оригинала. Чтобы сборка вместо этого
останавливалась, поставьте в `site.json` `"strict_translations": true`.

В словарях ищутся только тексты на кириллице (исходный язык интерфейса — русский). Если ваши
тексты на английском и вы публикуете русскую версию, интерфейс станет русским, а тексты
останутся английскими.

Движок никуда не отправляет ваши тексты. Переводите сами, с помощью человека, которому
доверяете, или удобной вам программой — и проверяйте результат: машинный перевод путает
степени родства и старинные слова.
