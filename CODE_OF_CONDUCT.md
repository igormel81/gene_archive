# Code of conduct / Правила поведения

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Be kind and patient: many people here are new to both genealogy and GitHub. Family history touches
painful topics — wars, repressions, emigration, adoption; treat other people's families with respect.
Problems: report privately to the maintainer through the contact in the GitHub profile.

Проект следует [Contributor Covenant 2.1](https://www.contributor-covenant.org/ru/version/2/1/code_of_conduct/).
Будьте доброжелательны и терпеливы: многие здесь впервые и в генеалогии, и на GitHub. История семьи
касается тяжёлых тем — войн, репрессий, эмиграции, усыновления; относитесь к чужим семьям с уважением.
О нарушениях сообщайте сопровождающему закрыто, через контакты в профиле GitHub.
