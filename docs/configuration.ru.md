# Настройки: `site.json`

**[English version](configuration.md)**

`site.json` лежит рядом с `family_tree.json`. Все ключи необязательны, кроме `title`;
незнакомый ключ — ошибка, чтобы опечатка не прошла незамеченной. Со строкой `"$schema"` (её добавляет `gene init`) редактор подсказывает ключи и их смысл. Полный пример —
[`example/site.json`](../example/site.json).

```json
{
  "title": "Семейный архив Ивановых и Петровых",
  "short_title": "Ивановы и Петровы",
  "description": "Документы, фотографии и рассказы двух семей из Рязанской губернии.",
  "base_url": "https://example.org/family/",
  "languages": ["ru", "en"],
  "root_person": "I1",
  "start_person": "I4",
  "quick_focus": [{"label": "Линия отца", "person": "I4"}],
  "branches": [{"id": "ivanov", "title": "Ивановы", "focus": "I9", "about": "Село Красное → Москва"}],
  "questions": [{"person": "I9", "text": "Где похоронен Пётр Иванович?"}],
  "story": {
    "timeline": [["1895", "Свадьба в Красном", "s-wedding"]],
    "places": [["Красное", "Красн"]],
    "branch_tags": {"s-wedding": ["ivanov"]},
    "branch_names": {"ivanov": "Ивановы"},
    "branch_colors": {"ivanov": "#2f6f8f"}
  },
  "surname_variants": {"Иваннов": "Иванов"},
  "privacy": {"hide_living": true, "living_years": 100},
  "comments": false,
  "contact": {"email": "family@example.org", "label": "Написать нам"},
  "links": [{"label": "Наш фотоальбом", "href": "https://example.org/album"}],
  "head_html": "",
  "strict_translations": false,
  "min_surname_page": 3,
  "gedcom_version": "5.5.1"
}
```

| Ключ | По умолчанию | Что значит |
|---|---|---|
| `title` | «Family archive» | название сайта: вкладка браузера, выдача поисковиков, картинка древа |
| `short_title` | = `title` | название в шапке |
| `description` | "" | одно предложение для поисковиков и превью ссылок |
| `base_url` | "" | адрес сайта с `/` на конце. Включает `sitemap.xml`, `robots.txt`, канонические ссылки и ссылки на языковые версии. `gene build --base-url` его заменяет |
| `languages` | `["en"]` | языки интерфейса: `ru`, `en`, `ro`. Первый публикуется в корне сайта, остальные — в `/en/`, `/ro/`… |
| `content_language` | первый язык | язык, на котором написаны ваши тексты |
| `root_person` | `root_person_id` из данных | человек, «о котором» архив: от него считается родство и поколения для приватности |
| `start_person` | главный человек | кто стоит в центре, когда открывается древо (часто дедушка — так видно больше) |
| `quick_focus` | `[]` | кнопки над древом, ставящие человека в центр |
| `branches` | `[]` | ветви семьи: `id`, `title`, `focus` (человек), `about` |
| `questions` | `[]` | вопросы к родственникам, каждый привязан к человеку; ответы появляются в его карточке |
| `story` | `{}` | страница «История», см. ниже |
| `surname_variants` | `{}` | написания, которые сливаются в одну фамилию на страницах фамилий и в боковой панели древа |
| `privacy.hide_living` | `true` | скрывать живых (см. [формат данных → Приватность](data-format.ru.md#приватность)) |
| `privacy.living_years` | `100` | люди, рождённые не раньше стольких лет назад и без записи о смерти, считаются живыми |
| `comments` | `false` | `true`, если сайт работает с сервером комментариев (`gene serve`, Docker). На статическом хостинге оставьте `false` — формы комментариев скрыты |
| `contact` | нет | `email` и `label` кнопки-конверта в шапке |
| `links` | `[]` | дополнительные пункты меню «Ещё» |
| `head_html` | "" | HTML, который добавляется в `<head>` каждой страницы: счётчики, метки подтверждения |
| `strict_translations` | `false` | останавливать сборку, если у какого-то вашего текста нет перевода (см. [переводы](translations.ru.md)) |
| `min_surname_page` | `3` | страницы фамилий делаются для фамилий, у которых не меньше стольких людей |
| `gedcom_version` | `"5.5.1"` | версия `family_tree.ged` на странице «Архив»: `"5.5.1"` (читают MyHeritage, Ancestry, Geni, Gramps и большинство программ) или `"7.0"` |

## Страница «История»

`content/story.html` — ваш рассказ ([страницы с текстом](content.ru.md)). Ключ `story`
добавляет к нему навигацию:

- `timeline` — `[год, короткий текст, id раздела]`: лента «По времени»; нажатие прокручивает
  к разделу.
- `places` — `[название, регулярное выражение]`: фильтр «По местам». Подсвечиваются абзацы,
  текст которых подходит под выражение. Сборка размечает их по оригиналу, поэтому фильтр
  работает и в переведённых версиях.
- `branch_tags` — `{id раздела: [id ветвей]}`: цветные метки под заголовком раздела.
- `branch_names`, `branch_colors` — подписи и цвета этих меток.
